# BORUIX

用 Rust 从零实现的 x86_64 操作系统。

**[Wiki](https://github.com/BRX-Boruix/wiki)** —— 从这里开始，含安装、使用教程与项目历史。

主要仓库：

- [`kernel`](https://github.com/BRX-Boruix/kernel) —— 内核
- [`tools`](https://github.com/BRX-Boruix/tools) —— 构建、打包与验收
- [`init`](https://github.com/BRX-Boruix/init) · [`shell`](https://github.com/BRX-Boruix/shell) · [`login`](https://github.com/BRX-Boruix/login) —— 系统程序
- [`libsys`](https://github.com/BRX-Boruix/libsys) · [`libc`](https://github.com/BRX-Boruix/libc) · [`libline`](https://github.com/BRX-Boruix/libline) —— 库

其余守护进程、用户态驱动与验收程序见 [仓库列表](https://github.com/orgs/BRX-Boruix/repositories)。

各仓库主要采用 MIT License。

---

An x86_64 operating system implemented from scratch in Rust.

**[Wiki](https://github.com/BRX-Boruix/wiki)** — start here for installation, usage tutorials, and project history.

Main repositories:

- [`kernel`](https://github.com/BRX-Boruix/kernel) — the kernel
- [`tools`](https://github.com/BRX-Boruix/tools) — build, packaging, and acceptance
- [`init`](https://github.com/BRX-Boruix/init) · [`shell`](https://github.com/BRX-Boruix/shell) · [`login`](https://github.com/BRX-Boruix/login) — system programs
- [`libsys`](https://github.com/BRX-Boruix/libsys) · [`libc`](https://github.com/BRX-Boruix/libc) · [`libline`](https://github.com/BRX-Boruix/libline) — libraries

Daemons, user-space drivers, and acceptance programs are listed in the
[repository list](https://github.com/orgs/BRX-Boruix/repositories).

Repositories are mostly under the MIT License.
